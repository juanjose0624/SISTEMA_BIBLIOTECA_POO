# 📚 Library Management System

A web-based Library Management System developed as the final academic project for the **Object-Oriented Programming (OOP)** course.

The application allows efficient management of books through a user-friendly interface and demonstrates the integration of frontend, backend, and database technologies.

---

## 🚀 Features

- Book registration
- Book editing
- Book deletion
- Book search
- Dynamic user interface
- Database management with MySQL
- Data integrity using database triggers
- Responsive web interface

---

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- PHP

### Database

- MySQL
- phpMyAdmin
- SQL Triggers

### Development Environment

- XAMPP

## ▶️ Installation

1. Clone the repository.

```bash
git clone https://github.com/juanjose0624/SISTEMA_BIBLIOTECA_POO.git
```

2. Copy the project into the **htdocs** folder of XAMPP.

3. Start **Apache** and **MySQL**.

4. Import the database using **phpMyAdmin**.

5. Open your browser and navigate to:

```
http://localhost/SISTEMA_BIBLIOTECA_POO/
```
